All sample data for the demo lives here:
- `sample-data.json` — the business, 12 customers, 40 invoices with line items, older payment history and expenses (money in paise). Generated by `gen/gen_seed.py` from the same values as the database seed `backend/src/main/resources/db/migration/V2__seed.sql`, which is what the running app reads (MySQL) and what "Reset demo" restores.
- `bank-statement.csv` — the sample statement for the Payments screen. It covers all six flag types: exact, part, several invoices in one payment, possible TDS, overpayment, payment against a disputed invoice, plus an unknown cash deposit.
- `templates.js` — reminder messages per ladder stage in English and Hindi.
- `config.js` — GST rates, ladder defaults, buffer, units. Live values come from `/api/config`.
